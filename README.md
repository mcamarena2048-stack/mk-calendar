# 📅 MK Calendar v8.0

**MK Calendar** is a lightweight, modern, and high-performance desktop application

---

## 🚀 Key Features
- **Native Dark Mode:** Interface optimized to reduce visual strain.
- **Productivity Tracking:** Percentage-based progress tracking and status labels for each day.
- **Intuitive Navigation:** Quickly switch between months or return to the current day with a single click.

---

## 📖 User Manual

### 1. Calendar Navigation
- `<` / `>` : Move forward or backward through the months of the year.
- **Today** : Instantly return to the current month and day.
- **All** : View a summary of all activities.
- **☰ (Menu)** : Access application settings and preferences.

### 2. Creating and Managing Events
1. Click on any numbered day in the calendar.
2. Enter the name of the task or event (e.g., *WORK*).
3. Adjust the progress percentage (the green indicator will update automatically as you complete the task).
